\head{Problem.} Autonomous agents retrieve knowledge, interpret images, use tools, and reason through multistep plans. An unnoticed error can invalidate an otherwise plausible trajectory: a resupply agent may read the quantity from the wrong row of a photographed inventory sheet and pass it to a planning tool. Outcome rewards reveal only that the plan failed; generic self-critique may miss the original visual error. Reliable agents need to identify the faulty reasoning step and choose an appropriate correction.
\par\head{Central hypothesis.} We hypothesize that typed, evidence-linked self-assessment improves both inference-time recovery and learned reasoning policies. Agents that localize why a step fails should outperform outcome-only learning and scalar process rewards on unseen tasks at matched cost. By distinguishing errors in observation, inference, and action, agents can select targeted corrections and recognize when further attempts are unlikely to help.
\par\head{Research plan.}
\begin{itemize}
\item \textbf{Develop neuro-symbolic representations of evidence-grounded agent reasoning.} Connect neural interpretation of text, images, and tool observations to structured representations of entities, events, preconditions, and inferential dependencies. Explicitly track alternative interpretations and provenance so symbolic checks can distinguish unsupported observations from invalid deductions or actions. Investigate when evidence and inference constraints can expose inconsistencies despite uncertain perception, and how to maintain valid conclusions as observations or external states change.
\item \textbf{Diagnose failures across perception, reasoning, and action.} Develop self-assessment methods that infer the likely origin and propagation of failures in multistep agent trajectories, separating faulty observations, invalid inferences, planning errors, and incorrect tool executions. Rather than scoring isolated steps, investigate how a verifier can use evidence provenance, action preconditions, and counterfactual checks to distinguish root causes from downstream symptoms, including cases with multiple interacting errors. Learn calibrated diagnostic uncertainty and determine when available evidence is insufficient for a reliable diagnosis. Test transfer to naturally occurring failures, unfamiliar tools, and new visual environments.
\item \textbf{Turn diagnosis into agent self-improvement.} Condition the next action on the diagnosed failure: re-examine an image region, retrieve a missing fact, repair a tool argument, backtrack, or abstain. Use error-aware process feedback and successful corrective trajectories to train improved policies, while checking final outcomes independently to detect reward exploitation. Compare type-conditioned correction training against scalar process rewards, and test whether reducing one error type causes new failures elsewhere. Measure improvement across training rounds as well as immediate repair success, including cases where repeated self-correction wastes resources.
\end{itemize}
\head{Evaluation and expected outcomes.} Evaluate on \href{https://proceedings.neurips.cc/paper_files/paper/2024/hash/e560a0b22e4432003d0dba63ff8dc457-Abstract-Datasets_and_Benchmarks_Track.html}{\textcolor{blue}{MEQA}}, \href{https://arxiv.org/abs/2311.12983}{\textcolor{blue}{GAIA}}, and \href{https://arxiv.org/abs/2406.12045}{\textcolor{blue}{$\tau$-bench}}, supplemented by controlled trajectories with independently verified error types and outcomes. Measure diagnosis accuracy and calibration, corrective-action success, and final task performance relative to tool cost. Compare with outcome-only RL, scalar process rewards, and LLM self-critique at matched computational budgets, separating diagnostic quality from downstream recovery.
\par\head{Naval relevance.} A Naval logistics support agent may combine a photographed inventory list, written guidance, and a resupply-planning tool. If it reads the wrong row, a useful self-assessment identifies the suspect image region and prompts a targeted correction before the tool result is trusted. This addresses the program's interests in uncertain reasoning and self-assessment, visual understanding, and the integration of knowledge, learning, and planning.
