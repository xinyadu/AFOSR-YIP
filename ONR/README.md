## Review before sending

- Confirm the PO still manages the intended portfolio and verify the correct email address.
- Review and sharpen the central scientific hypothesis and the Navy-relevance paragraph for each recipient.
- The LaTeX/PDF versions are checked by GitHub Actions for a single page; review the PDF after any revision.
- Check scientific claims carefully. Do not narrow these informal PO notes solely to avoid conceptual overlap with other proposals; address any required support disclosures when preparing a formal application.
- Do **not** upload or quote third-party confidential proposal documents.
- Submit **one full YIP proposal** via university officials, not multiple formal white papers.
