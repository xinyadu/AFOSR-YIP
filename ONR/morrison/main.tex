\head{Problem.} Naval command nodes must reason from reports that arrive late, out of order, or not at all. An afloat node may first receive a warning about an unidentified vessel and later learn it is scheduled support traffic; a shore node may receive these messages in reverse order. Naive summarization can leave the nodes with conflicting event histories even after they obtain the same evidence. The challenge is not just distributing reports, but reconciling uncertain event identities, corrections, and evolving interpretations without requiring continuous connectivity.
\par\head{Central hypothesis.} We hypothesize that separating immutable evidence from revisable event interpretations makes distributed reasoning both more consistent and more useful under intermittent communication. An order-independent evidence layer can preserve what each source actually reported, while explicit competing hypotheses and question-directed updates allow nodes to reconcile uncertain events without erasing conflicts or repeatedly transmitting the full record.
\par\head{Research plan.}
\begin{itemize}
\item \textbf{Represent evidence separately from event hypotheses.} Extract source-linked assertions about actors, locations, times, identities, and event relations, including explicit corrections and retractions. Store incoming assertions as persistent evidence while maintaining revisable hypotheses about which reports concern the same event. Preserve competing event interpretations and their support, rather than overwriting earlier reports with whichever message arrived last.
\item \textbf{Reconcile distributed event interpretations.} Develop a two-layer fusion mechanism: order-invariant merging of source assertions, followed by evidence-linked reconciliation of uncertain entity matches, event relations, and corrections. Use shared identifiers and explicit conflict sets to prevent duplicate or delayed messages from silently changing conclusions. Establish conditions under which nodes with the same evidence recover compatible event hypotheses, and expose unresolved ambiguity rather than assuming that mergeable records make neural interpretations identical.
\item \textbf{Select updates by their decision relevance.} Express commanders' standing information needs as queries over the evolving event graph. Under limited bandwidth, select messages that correct an important inference, resolve a conflict, or materially change the support for a current answer; avoid sending redundant reports. Build receiver-aware summaries with links to underlying evidence, allowing each node to distinguish supported conclusions from questions still unresolved by its local view.
\end{itemize}
\head{Evaluation and expected outcomes.} Partition \href{https://aclanthology.org/2022.emnlp-main.60/}{\textcolor{blue}{MAVEN-ERE}}, KAIROS-style event scenarios, and \href{https://proceedings.neurips.cc/paper_files/paper/2024/hash/e560a0b22e4432003d0dba63ff8dc457-Abstract-Datasets_and_Benchmarks_Track.html}{\textcolor{blue}{MEQA}} questions across nodes with delayed, duplicated, missing, and reordered reports. Compare evidence fidelity, reconciliation of conflicting event hypotheses, and query-relevant communication against full replication and chronological overwrite baselines.
\par\head{Naval relevance.} During distributed maritime operations, afloat and shore nodes may encounter conflicting vessel identifications and delayed corrections. Reconciliation of source-linked event hypotheses and selective sharing of decisive updates could support a more coherent common tactical picture across intermittent links, consistent with ONR's Command and Control interests in uncertain and out-of-sequence information.
